# 粥霸天 Web Desktop 工程

## 固定版本

- Cocos Creator 3.8.8
- 首发平台：Web Desktop
- 设计分辨率：1280 × 720 横屏
- 运行配置：`assets/resources/data/`
- 主场景：`assets/scenes/Store.scene`

不要用其他 Creator 版本打开后保存工程。移动端不属于当前首发构建。

## 打开与预览

1. 启动 Cocos Creator 3.8.8。
2. 打开本目录 `游戏工程/BaTian`。
3. 等待资源导入完成，打开 `assets/scenes/Store.scene`。
4. 使用浏览器预览。首屏应显示粥铺、Blender 导出的锅与灯、顾客、订单和操作按钮。

## 构建

在 Creator 的构建发布面板选择 Web Desktop，并使用项目根目录的
`buildConfig_web-desktop.json`。输出目录为 `build/web-desktop`。

构建前必须满足：

- Creator 版本为 3.8.8；
- 配置校验通过；
- 发布包不显示调试入口；
- `Store.scene` 是启动场景。

## 资源导入约定

Blender 源文件采用米制、Z 轴向上并应用缩放。导出格式为 GLB，运行资源放在
`assets/resources/models/`。原点位于物体接地点；锅位于锅底中心。样板源文件和导出说明见
项目根目录的 `美术源文件/样板/`。

## 规则验证

纯规则验证位于 `tests/`。它覆盖配置、固定步长、锅、订单、存档和重复操作；
浏览器画面仍需使用实际 Web Desktop 构建检查。

文档 04/05 的规则表在 `assets/resources/data/rules/`，并与项目根目录的 `数据/规则/` 保持一致。
启动时先校验这套表，错误会指出文件名和 ID。灰盒开局只有炭火 A，第二口锅要等买下 U01。第一日按钮是白粥和皮蛋瘦肉粥。
下锅前要先买米并处理完。熬煮中加料，出餐窗口里调味和选碗。盛碗后摆盘 3 秒。结果写成刚好、夹生、过火或糊底。
顶栏是这一天的阶段、剩余时间和铜钱。左侧是当日客人和备料库存，不盖住出餐柜台。底栏按钮会挡住后面的工位射线。锅要搅拌或快糊时，顶栏下方写出文字，不只靠颜色。窗口比画面更窄时，这一行仍留着。备料 90 秒，可提前开门。420 秒后来客停止。没送到的单不扣铜钱。
打烊才把实收、小费和租金写入铜钱包。钱包不会变成负数。付不出租金会欠租，铺子仍可进入下一日。
营业中每 30 秒、切到后台和打烊时写入本地档。刷新后锅、订单、铜钱和随机进度照原样暂停恢复。坏档或较新格式不会覆盖原档，已日结的一天也不会再次入账或扣租。
旧的金币短计时不再推动这一天。
用下面的命令检查规则：

```text
node tests/rules.test.cjs
```
